# FlyWireASCA v0.1.0 Release

Date: 2026-10-11
Release type: first preserved research/engineering baseline
State: post-A014 / pre-A015

## Purpose

v0.1.0 preserves the complete FlyWireASCA system after A014 has been closed and
before A015 End-to-End Unified Agent Runtime is activated or implemented.

This release is intentionally a stable historical checkpoint. It allows later
A015 work to evolve toward a new unified agent runtime while retaining an exact
recoverable copy of the qualified A001-A014 architecture, evidence, tests, and
documentation.

## Important limitation

v0.1.0 is not yet the intended end-to-end autonomous agent runtime.

The release retains the qualified A014 natural-language structural routing and
A013 relation-aware recall components, while the frozen A009 integrated loop
still expects prepared internal inputs.

The next architectural direction is documented in:

`docs/development/reports/ASCA-20261011-full-session-handoff-post-a014-a015-unified-agent-runtime-direction.md`

The user selected Approach 3 for the future A015 direction: a new top-level
unified agent runtime, with Stage A internal end-to-end autonomy qualified first
and controlled real-tool Stage C as the long-term target.
