# A006 Working Set / Selective Activation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add deterministic multi-query convergence and strict bounded working-set selection on top of A005 vector retrieval, then qualify whether selective activation preserves required memory evidence while shrinking active state relative to exhaustive and single-best controls.

**Architecture:** A006 consumes existing `VectorMemoryResult` values, merges repeated memory evidence by `memory_id`, computes bounded-union activation, applies strict active-memory and working-set budgets, and emits existing A002 `ActivationState`/`WorkingSet` contracts plus auditable support metadata. Portable qualification uses synthetic A005 results; physical qualification composes the already-qualified A005 local `qwen3-embedding:0.6b` retriever with A006 without calling the A004 generative model.

**Tech Stack:** Python >=3.11 standard library only, frozen dataclasses, `Enum`, deterministic tuple sorting, pytest, existing A002 control contracts, existing A005 vector-memory retrieval, local Ollama `qwen3-embedding:0.6b` only for physical qualification.

**Spec:** `docs/superpowers/specs/2026-10-09-a006-working-set-design.md`

## Review Focus

1. **Duplicate or inconsistent provenance:** duplicate source cue IDs, duplicate query IDs, duplicate memory IDs inside one malformed result, or conflicting immutable metadata for the same memory across cues must fail closed; pin in Tasks 1-2.
2. **Floating-point tie semantics:** boundary-tie detection must compare activation/max-similarity/support-count ranking keys before memory-ID tie-break and must not use proposition confidence; pin in Task 2.
3. **Zero/negative similarity handling:** similarity <= 0 must not create positive support or inflate support count, while original A005 hit similarity remains auditable; pin in Tasks 1-2.
4. **Baseline contamination:** SINGLE_BEST and EXHAUSTIVE must reuse the same validated evidence rather than silently changing metadata/model/profile requirements; pin in Task 3.
5. **Physical-fixture tuning:** final physical text, threshold, `top_k`, and A006 budgets are frozen before final run and must not be changed after observing final-case outcomes; pin in Task 5 evidence/tests.
